# 06 — Từ điển ngành sầu riêng (dùng trong lời)

| Từ | Nghĩa |
|---|---|
| hàng loại một / hàng đẹp | trái đạt chuẩn xuất, đủ ký, gai đều, không sâu |
| hàng dạt | trái bị loại (méo, trầy, nhẹ ký, sượng), giá thấp |
| bắt dạt / tỷ lệ dạt | kho lựa ra hàng dạt; phần trăm hàng bị loại |
| trừ bì | trừ khối lượng sọt, cuống, bao |
| ép giá | hạ giá so với lúc thỏa thuận |
| cò | người trung gian dẫn mối, ăn hoa hồng |
| chốt kèo / chốt giá | thống nhất giá, lượng, ngày cắt |
| đặt cọc / bỏ cọc / phạt cọc | tiền cọc; người mua bỏ không mua (mất cọc); người bán hủy phải trả gấp đôi |
| thợ cắt | đội hái sầu riêng |
| cơm vàng, hạt lép | chất lượng múi tốt |
| sượng, sâu, cháy múi | lỗi chất lượng |
| cân đối chứng | cân thứ hai để kiểm tra cân chính |
| bầm trầy, toang, sập giá | lời dân dã diễn tả thua lỗ |
| thuận mua vừa bán | cả hai bên đồng ý, công bằng |
